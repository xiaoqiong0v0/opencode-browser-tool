浏览器输入 / 交互测试页

用法：① 执行按键 / 输入命令后看下方大号状态条——显示最后一个事件的类型、key、code、isTrusted 与总条数； isTrusted=false 表示合成事件（自动化工具派发，红底），true 表示真实用户操作（绿底）。 ② 状态条若停留在「尚未收到任何事件」、或只有 click 而没有 key 事件 → 按键没有到达页面。 ③ 「清空日志」按钮重置状态条、日志面板、window.__events 与 #dump。 ④ 验证上传：`upload_file --selector #file --filePath <存在的文件>` 后看 #file-info 的 files.length 与文件名，并应出现一条 change 事件；不存在的路径应直接报错。 ⑤ 验证拖拽：`drag --sourceSelector #drag-src --targetSelector #drop-zone` 后看 #drag-info 的 dragstart/dragover/drop 计数与 drop 时 getData('text/plain') 的值（真实 DnD 应为 DRAG-OK）。 ⑥ 验证点击/悬停：`click --selector #mb` 后看 #mb-info 的 mousedown/mouseup/click 计数与 last 坐标（isTrusted 应为 true）； `click --selector #covered-btn` 应报「被遮挡」错误且 #covered-info 计数不变（对照 `#synth-covered` 走 el.click() 会 +1）。 ⑦ 悬停：`hover --selector #hover-target` 后 #hover-info 的 matches:hover=true 且 bg 变绿； iframe 内用 `iframe_click --iframeSelector #ifr --selector #ifr-btn`，看 #ifr-info 计数。 ⑧ 表单填写：`fill --selector #text --value hello` 后 #text 值应为 hello；`fill --selector #controlled --value abc` 应更新 #controlled-info 的 state 且 trusted+1（untrusted 输入会被回滚）；`select --selector #sel --value o3` 应选中 o3 并出现可信 change；`iframe_fill --iframeSelector #ifr --selector #ifr-text --value abc` 应填入 iframe 输入框。 非 Windows 下上述命令会带 (degraded: ...) 标注。
